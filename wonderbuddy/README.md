# WonderBuddy Kids Chatbot

A simple browser-only chatbot demo for young children. It uses playful, predefined questions and clickable choices about animals, imagination, superpowers, treasure and dragons.

## Run
Open `wonderbuddy/index.html` in a browser.

## Safety
The demo does not ask for names, addresses, school details, photos, contact information or other personal information. A production child-facing product should add appropriate parental consent, privacy, moderation and child-safety controls.
