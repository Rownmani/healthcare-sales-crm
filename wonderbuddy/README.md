# WonderBuddy Kids Chatbot

A simple browser-only chatbot for fun interactions with young children.

## Run
Open `index.html` in the `wonderbuddy/` folder in a browser.

## Features
- Playful questions about animals, superpowers, treasure, planets, and dragons
- Large clickable answer choices
- Restart/play again flow
- No personal information collection

## Child safety
This demo intentionally avoids requesting names, addresses, school details, photos, phone numbers, or other personal information. For production use, add age-appropriate safety controls, parental consent where required, privacy protections, content moderation, and secure data handling.
